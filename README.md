# Pino Gare Rooftop Restaurant

One-page site for Pino Gare Rooftop Restaurant, 7th floor of the Orient Express Hotel, Sirkeci, Istanbul.

Static HTML, CSS and JavaScript in `index.html`, with self-hosted fonts, AVIF/WebP/JPEG images and a looping hero video (AV1 + H.264) under `assets/`.
Business details come from the restaurant's Google Maps listing and its own website. Imagery is illustrative.
